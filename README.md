I build two things, and they feed each other: **AI products** that go from zero to one, and the **agent systems** that run content and research operations at scale.

### AI Product Engineering

Shipping end-user products with LLMs at the core — resume intelligence, career guidance, memory-augmented agents.

- **[TiMem](https://github.com/TiMEM-AI/timem)** · contributor — temporal-hierarchical memory consolidation for long-horizon conversational agents
- **[ZhiXia 职虾](https://github.com/jessai2026/zhi-xia)** · creator — AI resume agent built on the OpenClaw framework
- **CareerPath** · solo dev *(private)* — AI resume builder with career-path guidance

### AI Content Ops & AI4Science

Multi-agent pipelines that research, write, review and publish — plus the editorial guardrails that keep them honest.

- **Multi-account WeChat publisher matrix** *(private)* — 5-agent editorial pipeline with medical/scientific red-line review
- **Hetu / Akasha content ops** *(private)* — social and long-form ops for [@hetu_protocol](https://x.com/hetu_protocol) and Advaita Labs
- **Symbiosis science video workflow** *(private)* — script → render → publish automation for science explainers
